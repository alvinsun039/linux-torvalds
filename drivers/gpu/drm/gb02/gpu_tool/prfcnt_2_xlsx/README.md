# 使用如下命令进行转换
```
./xlsx.pl 2 /path/to/layout.xlsx /path/to/primary.hex /path/to/secondary.hex
```
note: 2 is gb02 performance data, 1 is gb01 performance data
      layout.xlsx is performance counter layout
      primary.hex is performance counter set 0
      secondary.hex is performance counter set 1

      -o <output file name>
      -d debug
